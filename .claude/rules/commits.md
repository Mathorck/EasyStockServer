# Commits (overrides org git-workflow commit format)

Personal repo without Azure Boards tickets. Use Conventional Commits instead of `AB#<ticket>`:

`<type>(<optional scope>): <imperative short description>` (max 72 chars)

Types: `feat`, `fix`, `docs`, `refactor`, `test`, `chore`, `style`.

- No AI attribution, no "Generated with" footers
- Commit only what was explicitly requested
